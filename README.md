A one-line 1-star review written by a houseplant about the human who owns
it — an entry for the [One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)
bounty on [make.fun](https://make.fun/r/hv9zk8y5).

## The entry

> One star. He repotted me into a pot with no drainage holes, so I live in a swamp while he tells guests I'm 'thriving' — I'm not thriving, I'm marinating.

## How it works

`main.ts` (run by the harness with Node 22) writes that single line to
`/output/entry.txt`. The line is 153 characters — inside the 1–279
character gate — and the program refuses to write anything outside that
range.

```sh
node main.ts   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
